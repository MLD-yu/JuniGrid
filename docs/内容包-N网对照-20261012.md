# 附：术语——中文「内容包」在英文里叫什么

**结论：Nexus 自己没有这个官方叫法，官方词来自星露谷官方 Wiki / SMAPI，而且是两个不同的词。**

| 想问的东西 | 官方英文（出处） | 中文维基对应页 | 判据 / 定义 |
|---|---|---|---|
| 「内容包」字面直译 | **content pack**（星露谷官方 Wiki: `Modding:Content packs`；SMAPI 术语） | **模组:内容包** | manifest 里写 `ContentPackFor`；由某个**内容包框架**（Content Patcher / Alternative Textures / Json Assets…）加载，本质是"子模组"，**必须装前置框架** |
| 本 app「内容包」页管的东西（直接覆盖游戏本体 `Content\` 的 .xnb） | **XNB mod**（官方 Wiki: `Modding:Using XNB mods`；中文维基作「XNB模组」） | 模组:使用指南/入门、模组:编辑 XNB 文件 | Wiki 原话：*"An XNB mod replaces some of your game's .xnb files to change the game"*；wiki 明确说它**不推荐**（难装难卸、互相冲突、游戏一更新就坏） |

- **Nexus 官方**：只有游戏分类表，SDV（gameId 1303）官方分类共 **27 个**，里面**没有** Content Pack / XNB 之类的类目；
  这类 mod 实际挂在 `Visuals and Graphics` / `Characters` / `Portraits` / `Livestock and Animals` / `Miscellaneous` 等分类下。
  Nexus 的通用官方词只有 Mod / Files / Collections，没有"内容包"。
- 所以英文界面怎么写，取决于想指哪一个：
  - 指**本 app 这一页**（覆盖本体图片、无需 SMAPI）→ 准确词是 **XNB mods**（社区口语也叫 XNB replacer）。
    现在 `i18n/en.json` 用的是 `Content Packs`，**与 SMAPI 的 content pack 撞词**，语义会被懂行的用户理解成"要前置框架的包"。
    （en.json 里那句 "written straight into the game's own Content folder and work without SMAPI" 是在补救这一点。）
  - 指**生态里的内容包**（给 CP 等框架喂内容）→ **content packs**，这在官方 Wiki 里是带定义的术语，可以直接用。
- 依据（2026-10-12 实查）：
  - https://wiki.stardewvalley.net/mediawiki/index.php?oldid=71614 （Modding:Content packs）
  - https://wiki.stardewvalley.net/mediawiki/index.php?oldid=67357 （Modding:Using XNB mods，含 XNB vs SMAPI vs content pack 三列对照表）
  - https://zh.stardewvalleywiki.com/... `模组:内容包`（中文维基对 content pack 的官方译名就是"内容包"）
